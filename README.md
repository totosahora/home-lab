# 🎡 小小科学乐园（Little Science Park）

100 个面向 5-18 岁学生的物理、化学、数学网页小游戏，拖拽式交互，边玩边学。

## 在线试玩

部署后访问：`https://<用户名>.github.io/science-lab/`

## 本地运行

无需任何安装：直接用浏览器打开 `index.html` 即可（所有游戏均为零依赖单文件）。

## 目录结构

- `index.html` — 游戏大厅（学科/学段筛选、收藏、试玩记录、中英双语介绍）
- `games.js` — 游戏目录数据（100 个条目：物理 40 / 化学 25 / 数学 35）
- `games-en.js` — 英文介绍（名称 + 概念定义 + 通俗解释）
- `lab.js` — 共享工具库（音效/提示条/相机/手柄），供新游戏复用
- 其余 100 个 `.html` — 每个即一个独立游戏

## 设计理念

- 无失败状态：错误操作产生有趣的现象而非弹窗
- 即时反馈：一切操作立刻看到物理后果
- 可视化不可见的量：电流、力箭头、能量条、分子运动
- 拖拽为核心交互，鼠标/触屏通用
